# SZ-001 GOLF CLUB 360 · 提案文件

- `pitch-internal.html`：内部 Pitch 手册（Baron × 老王），仅供内部讨论，请勿外流。

- 客户版：https://bohamfu-ops.github.io/sz-001-pitch-docs/proposal-client.html
- 内部版：https://bohamfu-ops.github.io/sz-001-pitch-docs/pitch-internal.html
- 演示：https://bohamfu-ops.github.io/sz-001-pitch-docs/demo/

演示中的球场、球友、价格与订单都是虚构示范数据，只存在浏览者自己的浏览器里，右上「重设」可回到初始状态。照片与短片均为本机 AI 生成的原创素材。演示原始码在 b-labz 本机专案 `golf-club-360-demo`，以 `npm run build:pages` 产生 `demo/`。
